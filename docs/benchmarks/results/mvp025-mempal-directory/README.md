Whole-range R3 at `d3fe10577759570a7746932fe32080886a59eede` closed both earlier source-loss counterexamples but found one HIGH directory/lock ownership regression. Directory replacement at metadata fsync could redirect subsequent data writes behind another process's lock, or return success with no archive at the requested destination. The [complete R3 FAIL](https://github.com/RyderFreeman4Logos/akasha-otsuge/pull/60#issuecomment-6766373412) and focused probes remain unchanged here. Its exact canonical and hosted CI passes are supporting history, not waivers.

The repair replaces pathname-based writer ownership with one retained parent/directory owner. Child creation/open and metadata publication use that directory descriptor. It retains every used member descriptor, a directory lock and the compatible lock-file lock through buffered-sink destruction. The shared completion check binds the requested parent/root and member paths to those retained identities. Anonymous metadata and no-replace linking remain unchanged. No source schema, archive mapping or projection changes are introduced.

Replacing the lock filename also admitted a second writer. After repair, all cases reject and preserve foreign members; directory locking rejects the second writer. The focused continuation passed 21 archive and four mempal tests, one intentionally ignored supervisor child, all five actual SIGKILL phases, formatting and all-target Clippy. A follow-up lifetime audit keeps output ownership after buffered sinks in field-drop order; the final focused run repeats those checks on that final source.

The frozen baseline returns false success in all four; the candidate rejects all four and leaves every replacement untouched. Busy controls prove the independent lock is effective. Each candidate's parked original directory resumes, repeats byte-identically, imports and exports with identical neutral archive files. The candidate also replays the baseline's archive without changing any of its four files. All tiny SQLite fixtures, subprocesses and interposers were removed.
