## Issue 正文

\*\*覆盖需求：\*\*REQ-18、REQ-21。

\*\*目标：\*\*把存储 spike 的选择变为可持续使用的唯一权威数据层。

\*\*范围：\*\*实现原始证据、不可变 revisions、状态变化、作业和 outbox 所需的存储原语；定义提交边界、幂等键、schema migration、checkpoint、blob 校验、备份/恢复入口。派生索引必须可重建，不能成为事实权威。

\*\*非目标：\*\*不保留第二正式 backend，不使用 SQLite 隐藏保存元数据，不把覆盖旧内容当版本历史。

\*\*依赖：\*\*MVP-003。

\*\*验收测试：\*\*在提交前、提交中和提交后注入崩溃，恢复后只有完整提交或未提交状态；重复提交相同幂等键不会重复生效；备份恢复后内容 hash 和 revision 一致；正式依赖/运行文件清单没有 SQLite fallback。

\*\*完成证据/产物：\*\*Storage 实现、存储格式说明、迁移策略、恢复测试、备份校验报告。
