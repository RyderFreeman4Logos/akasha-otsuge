## Issue 正文

\*\*覆盖需求：\*\*REQ-10、REQ-14、REQ-15、REQ-21。

\*\*目标：\*\*用户可配置通知渠道；MVP 提供实际能使用的本地通知和 stdio 插件，而非只有抽象接口。

\*\*范围：\*\*Notifier 统一 envelope/capabilities；本地 inbox/list/ack 及可执行 stdio 示例插件；事件与 outbox 同一原子提交单元；持久重试、幂等键、provider message ID、合并/升级、失败可见状态和 ack。通知只携带必要摘要及 review 引用；channel 配置可热更。

\*\*非目标：\*\*不强制连接商业 SaaS，不承诺所有 provider exactly-once，不把投递成功/已读/ack 视为接受补丁或关闭 review。

\*\*依赖：\*\*MVP-008、MVP-019、MVP-022。

\*\*验收测试：\*\*真实本地和独立 stdio 插件均收到通知；提交后发送前、发送后记录前崩溃都可恢复；100 次同类失败合并而不吞掉重要升级；不支持 provider 幂等时重复风险清楚可识别；ack 与 review 状态独立；禁用渠道立即阻止后续投递。

\*\*完成证据/产物：\*\*插件协议和参考实现、可用 CLI、投递/崩溃测试、合并/ack 演示。
