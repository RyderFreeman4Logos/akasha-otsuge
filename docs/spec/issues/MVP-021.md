## Issue 正文

\*\*覆盖需求：\*\*REQ-03、REQ-11、REQ-13、REQ-23。

\*\*目标：\*\*能从软件实际执行结果追溯相关 agent run 和检索结果，且不夸大因果。

\*\*范围：\*\*实现 outcome 入口与可用命令 wrapper；记录 run ID、receipt IDs、base commit、相关 dirty diff/tree digest、构建产物、命令/退出结果和日志 refs；区分 returned/attached/cited-or-claimed-used/suspected/validated 等关系；支持测试框架或 CLI adapter 提交结构化结果。

\*\*非目标：\*\*不把被召回等同被使用，不把 exit 1 一律当事故，不只记录 Git commit 而忽略未提交修改，不需要图数据库。

\*\*依赖：\*\*MVP-006、MVP-011、MVP-016。

\*\*验收测试：\*\*针对未提交代码的失败能关联正确 tree；同一 run 多次构建不混淆产物；无关环境失败不自动产生记忆因果结论；fixture 中只有曝光的记忆被标为曝光；日志截断保留完整来源引用。

\*\*完成证据/产物：\*\*outcome wrapper/协议、关系语义说明、真实构建或测试失败样例、因果谨慎性测试。
