## Issue 正文

\*\*覆盖需求：\*\*REQ-06、REQ-07、REQ-10、REQ-11、REQ-12、REQ-20。

\*\*目标：\*\*外部 agent 能查证并修正记忆，同时核心保持版本、来源和权限一致。

\*\*范围：\*\*实现反馈入口和 editor 工作流；允许读取授权原文/代码、定位错误类型、提交带 expected revision/evidence/scope/reason 的精确 patch；由核心策略决定自动激活或 review；扩大 scope 使用单独授权；修订后索引和缓存立即按权威状态过滤。

\*\*非目标：\*\*不让 editor 任意写数据库/原始日志，不因一次局部失败修改全局偏好，不把所有失败归咎于记忆，不允许最后写入无条件覆盖并发修改。

\*\*依赖：\*\*MVP-016、MVP-019。

\*\*验收测试：\*\*正确修订、证据不足、scope 越界、伪造人审、重复 patch、并发冲突和补丁过期都有测试；原文不被改写；旧 receipt 可复核，新查询不再返回已撤回版本；一次真实外部 Runner 完成调查和受策略约束的修订。

\*\*完成证据/产物：\*\*patch 协议、权限/并发测试、修订审计、真实 editor 执行记录。
