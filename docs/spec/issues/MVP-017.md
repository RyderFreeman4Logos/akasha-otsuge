## Issue 正文

\*\*覆盖需求：\*\*REQ-05、REQ-07、REQ-08、REQ-20、REQ-21。

\*\*目标：\*\*从新采集原文中产生有来源的候选记忆，而不是直接将摘要写成用户真意。

\*\*范围：\*\*使用配置的 text endpoint 或已有 CLI AgentRunner 提取原子事实/偏好/决定候选；只有一个 CLI、没有额外 text/embedding/reranker endpoint 时仍能走完整基础路径；保存原文范围、scope 建议、条件和提取版本；后台 embedding/rerank 索引任务可重跑、可暂停、可恢复；对内部 memory-service 会话做明确来源标记，防止自我摘要递归形成无限提取循环。

\*\*非目标：\*\*不覆盖原文，不默认调用昂贵外部模型，不将自动候选伪装成人工确认，不持久化无法追溯的多层摘要链。

\*\*依赖：\*\*MVP-005、MVP-007、MVP-009、MVP-010、MVP-016。

\*\*验收测试：\*\*条件性陈述、否定、引用他人、临时选择和自动讨论不会被错误升权；重复事件/作业不重复创建有效版本；模型不可用时原文仍持久化；恢复后补齐索引且撤回条目不再返回；所有候选可跳回来源；至少一次仅有单 CLI 和已有认证的实际提取通过，不能因为缺少额外 API key 阻断。

\*\*完成证据/产物：\*\*提取工作流、版本化 prompt/schema、幂等/恢复测试、带原文对照的样例集。
