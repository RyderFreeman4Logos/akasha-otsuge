## Issue 正文

\*\*覆盖需求：\*\*REQ-03、REQ-04、REQ-05、REQ-17。

\*\*目标：\*\*只安装 Hermes 时支持日常 CLI/TUI、profile 和单独的外部 Runner。

\*\*范围：\*\*使用实施时官方 hooks 与 canonical session/export 路径；明确现代 Hermes 的持久来源，不盲目 tail 旧 JSONL；正确解析一行一个 session 的 export；记录 profile、父子 session、压缩/中断历史。Runner 支持单次执行、配置选择、取消及限制工具。

\*\*非目标：\*\*不把 Gateway-only hook 当所有界面都支持；不只依赖成功轮次的 post\_llm\_call；不将 human-input telemetry 中不含的答案编造成已保存。

\*\*依赖：\*\*MVP-011。

\*\*验收测试：\*\*其它三种 CLI 缺席时真实 CLI/TUI Caller 与 Runner 工作；至少两个 profile 不串线；中断轮次可回补；导出大小保护或读取失败清楚报告；压缩前原文、子 agent 来源、权限限制都有实测。

\*\*完成证据/产物：\*\*适配器、版本/模式支持表、真实 export fixture、profile 和恢复测试记录。
