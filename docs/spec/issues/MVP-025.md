## Issue 正文

\*\*覆盖需求：\*\*REQ-07、REQ-11、REQ-21、REQ-22。

\*\*目标：\*\*用户能保留已有 mempal 数据，并能将新系统数据迁出，不被新格式锁住。

\*\*范围：\*\*固定被支持的 mempal commit/schema，清点实际数据类型；只读导入原文、记忆、来源、时间/范围和可识别历史；缺少来源或审核证据时明确 unknown，不伪造人工批准。提供带 manifest、版本、blob 和关系的中立导出，以及增量/重复导入和恢复校验。

\*\*非目标：\*\*不原地修改旧 mempal 数据，不将 legacy reader 发展成第二正式 backend，不声称能重建旧系统从未保存的原文或历史。

\*\*依赖：\*\*MVP-004、MVP-005、MVP-006、MVP-007、MVP-019。

\*\*验收测试：\*\*从实际 mempal 样本导入，计数/hash/抽样内容和关系核对一致；重复导入幂等；损坏/未知版本安全拒绝并报告；新库 export→空库 import 后有效状态和历史 receipt 一致；旧源数据未变化。

\*\*完成证据/产物：\*\*迁移 CLI、支持版本清单、字段映射/缺失数据报告、真实迁移与往返验证结果。
