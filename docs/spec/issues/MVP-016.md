## Issue 正文

\*\*覆盖需求：\*\*REQ-02、REQ-03、REQ-04、REQ-06、REQ-11、REQ-16。

\*\*目标：\*\*主 agent 调用 consult 或 consult 加一句短意图后，由外部 agent 自行获取足够上下文和证据。

\*\*范围：\*\*开工前验证MVP-011冻结的参考集与规则commit/hash；随后实现调研prompt。runtime 自动提供 binding/context refs；hint 仅补充意图，不替代身份或权限。支持逐步 search/show/读取授权代码，必要时委派子 agent 及其后代；共享总 token/时间/并发/深度预算，保留谱系。最终返回精简结论、适用范围、证据、分歧/缺口和 receipt，支持继续展开原文。

\*\*非目标：\*\*不让主 LLM 手填大任务包，不强制每次简单查询都启动强模型，不固定 Claude 问/Codex 答；不把一次召回数量降低等同质量提高。

\*\*依赖：\*\*MVP-012、MVP-013、MVP-014、MVP-015。

\*\*验收测试：\*\*四种单 CLI 均能使用默认本 CLI Runner 完成 consult；空 hint 和短 hint 都工作；子孙越权、超预算、循环委派受到真实限制；默认一个 worker 与两个父 worker 同时委派时均不死锁，资源不足返回可回退的 DELEGATION\_UNAVAILABLE；某分支失败不丢其它证据；主输出符合预算且可通过 receipt/show 追溯；长本地请求不被外层提前中止。

\*\*完成证据/产物：\*\*consult CLI、运行树/预算报告、四单宿主实测、至少一个子孙委派和跨组合实测记录；完整组合验收由 MVP-027 覆盖。
