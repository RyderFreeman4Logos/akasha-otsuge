## Issue 正文

\*\*覆盖需求：\*\*REQ-07、REQ-09、REQ-10、REQ-11、REQ-15。

\*\*目标：\*\*不同用户可选择全自动、人工审核或混合策略，不把来源真实与是否允许执行混为一谈。

\*\*范围：\*\*实现候选激活/退休、review open/investigating/resolved/dismissed、人工确认/修改/否决、精确版本绑定；自动候选可按策略 active；人工 taste/约束在对应 scope 内优先，且支持局部例外和明确后继版本。提供可用 CLI review，不要求另建 Web UI。

\*\*非目标：\*\*不让有 open review 的全部记忆无条件停用，不将 ack 当批准；不允许自动修订继承旧版本的人审标签。

\*\*依赖：\*\*MVP-005、MVP-006、MVP-018。

\*\*验收测试：\*\*自动、人工和混合三种策略都有完整真实流程；相同候选在不同配置下得到预期生效结果；局部例外不废除无关全局 taste；人审修改保存原候选、修改差异和理由；热改策略影响按约定启动的新操作。

\*\*完成证据/产物：\*\*review CLI、策略矩阵、人工校准示例、独立状态机和权限测试。
