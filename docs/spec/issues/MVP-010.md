## Issue 正文

\*\*覆盖需求：\*\*REQ-02、REQ-08、REQ-11、REQ-18、REQ-20、REQ-23。

\*\*目标：\*\*无需外部调研 agent 也能直接获得相关且可追溯的记忆，查询不全量载入语料。

\*\*范围：\*\*实现关键词/标识符与向量检索、可配置 reranker、scope/有效版本过滤、适用高权威规则读取、渐进 show/range；查询产生实际 receipt。暴露索引进度、来源覆盖、模型和索引版本；模型离线时有明确的降级结果，而非伪装完整。

\*\*非目标：\*\*不自动把大量检索内容注入每轮上下文，不把未找到解释成用户没有偏好，不依靠已经过期的索引元数据决定条目仍生效。

\*\*依赖：\*\*MVP-005、MVP-006、MVP-009。

\*\*验收测试：\*\*中英混合、代码符号、版本号、长原文、不同 scope 和冲突记录测试；retired 记录即使仍在索引中也不默认返回；索引更新中能说明覆盖状态；原文按范围读取；预算限制可验证且 receipt 与实际输出一致。

\*\*完成证据/产物：\*\*search/show CLI、检索 fixtures、质量基线、索引一致性与撤回测试。
