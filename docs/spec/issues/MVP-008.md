## Issue 正文

\*\*覆盖需求：\*\*REQ-17、REQ-19、REQ-21。

\*\*目标：\*\*所有核心功能经命令行可调用，daemon 承担持续采集和后台任务，运行不依赖 MCP 或 TCP 监听。

\*\*范围：\*\*实现 Linux 私有 Unix socket、目录/socket 权限、peer 身份检查、版本化请求协议、大小限制、结构化退出码；实现有界 intake、持久 jobs、lease/重试、取消和重启恢复。将MVP-006的历史查询、diff和receipt API接入生产CLI/IPC，配置管理命令也在本Issue完成实际接入。daemon暂停时，受支持的CLI读取/采集降级路径明确，不能无限等待；MVP可明确返回DAEMON\_UNAVAILABLE，不要求另做daemonless数据写入路径。

\*\*非目标：\*\*不默认开放 HTTP 端口，不建设 MCP server，不宣称 socket 权限能阻止同 UID 进程直接访问其可读文件。

\*\*依赖：\*\*MVP-002、MVP-004、MVP-007。

\*\*验收测试：\*\*端口检查无意外监听；另一非特权 OS 用户不能访问私有 IPC/数据；过大请求、版本不兼容和繁忙情况返回稳定错误；服务重启后accepted jobs不丢失或重复生效；安装后的CLI可以执行配置管理、历史查询、diff和receipt查看，并与组件API结果一致。

\*\*完成证据/产物：\*\*CLI/IPC 协议、daemon 生命周期命令、作业状态接口、权限与恢复测试。
