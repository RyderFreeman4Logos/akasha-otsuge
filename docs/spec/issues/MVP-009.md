## Issue 正文

\*\*覆盖需求：\*\*REQ-08、REQ-15、REQ-16。

\*\*目标：\*\*embedding、reranker、text LLM 都可独立配置，并真正享有默认 1700 秒单次请求预算。

\*\*范围：\*\*实现 provider 配置、输出校验、错误分类、取消、限流和有界 batch；优先适配用户实际可用的本地服务契约，不硬编码模型名称。记录有效 request/idle/worker/RPC/job deadlines；长任务可返回 job ID 后继续，不能被 CLI 等待时限杀死。

\*\*非目标：\*\*不默认购买昂贵远端 API，不强迫三类模型来自同一服务，不把本地模型延迟当 daemon 故障；不以重试掩盖配置中的 60/120/300 秒截断。

\*\*依赖：\*\*MVP-002、MVP-008。

\*\*验收测试：\*\*三类 endpoint 正常、畸形、慢响应和断连均有测试；虚拟时钟覆盖边界；至少一次真实墙钟长测经完整 daemon/job/客户端路径在默认 1700 秒接近上限处成功返回，并验证超过预算的明确超时；连续多阶段请求不会被更短总 deadline 截断；热更 endpoint 仅作用于按规则新启动的调用。

\*\*完成证据/产物：\*\*provider 配置示例、实际兼容服务记录、每层有效 deadline 报告、真实长测起止时间和结果。此 Issue 的长测走生产 daemon 与直接 provider client；CLI Runner 长测在对应宿主 Issue 及 MVP-016/027 完成，不反向依赖尚未实现的适配器。
