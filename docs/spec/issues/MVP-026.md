## Issue 正文

\*\*覆盖需求：\*\*REQ-01、REQ-04、REQ-15、REQ-16、REQ-17、REQ-22、REQ-24。

\*\*目标：\*\*另一位用户能安装并使用，不需要理解内部实现或同时拥有四家 CLI。

\*\*范围：\*\*构建 Linux 发行包和校验信息；提供 daemon 启停、按宿主安装/移除 adapter、配置备份/升级、迁移/导出、doctor、故障恢复文档；明确权限、数据目录、无 MCP 路径、可选 hint、模型配置、1700 秒语义、review/通知模式和资源档。架构支持以总览目标矩阵为准，不虚标只编译未运行的平台。

\*\*非目标：\*\*不交付非 Linux 原生包装，不要求所有 CLI 都已安装，不覆盖用户已有 hooks/config，不将重装软件作为处理每种故障的办法。

\*\*依赖：\*\*MVP-012、MVP-013、MVP-014、MVP-015、MVP-023、MVP-024、MVP-025。

\*\*验收测试：\*\*干净 Linux 安装后仅选择一种 CLI 即可完成采集、consult、review 和通知；升级保留数据/配置与 pending jobs；卸载撤销本项目集成而不删除用户历史；文档中的所有示例命令均实际执行过。

\*\*完成证据/产物：\*\*发行候选包、checksums、安装/升级/卸载记录、四宿主教程、备份恢复和支持矩阵。
