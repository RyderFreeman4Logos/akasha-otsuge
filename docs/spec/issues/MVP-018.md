## Issue 正文

\*\*覆盖需求：\*\*REQ-04、REQ-06、REQ-07、REQ-09、REQ-10。

\*\*目标：\*\*用户不参与每轮对话时，也能探索需求和工程方案，同时保留自动来源与未解决问题。

\*\*范围：\*\*可配置 interviewer/expert/reviewer 角色；允许一个 CLI 多个独立上下文，也允许不同 Runner 组合；独立初答、交叉质询、证据核查、候选输出、停止条件和共享预算；保存问题依赖、假设、分歧和讨论来源。

\*\*非目标：\*\*不要求两家订阅，不强制达成共识，不把多数票或强模型意见当真人偏好，不在此处写死人工审核必经。

\*\*依赖：\*\*MVP-016、MVP-017。

\*\*验收测试：\*\*单 Runner 和混合 Runner 都能结束并产出来源完整的候选；有分歧时保留分歧而非伪造一致；依赖尚未解决的问题明确标记假设；达到轮数/预算停止且可恢复；自动来源不越权。

\*\*完成证据/产物：\*\*配置样例、真实单/组合讨论记录、候选与源事件映射、停止和恢复测试。
